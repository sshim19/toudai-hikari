# 灯台の光

左の親指を弧の上でずらして明かりの向きを決め、右の親指で明るさを整え、今日の船を礁のあいだから港へ導くゲームです。同じ日は、だれが遊んでも同じ海です。携帯は横向きで、両手で遊びます。

## 遊び方

1. 画面を横向きにして、「点ける」を押します。制限時間は75秒です。
2. 左の親指を弧の上でずらして、光の向きを決めます。右の親指を縦の溝の上へずらすと明るく、下へずらすと暗くなります。霧が濃いときは明るくして、右の霧笛を指で押して鳴らします。マウスなら、片方ずつ動かすことができます。
3. 光が船に乗っているときだけ、船は航路を保ちやすいです。礁の手前では霧笛を鳴らします。油と空気は限りがあるので、いつも最大にはできません。
4. 22秒を過ぎれば「仕舞う」で早めに確定しても構いません。今日の船をすべて港へ入れたら、22秒前でも確定します。時間が来ると、そこまでの結果で終わります。座礁しても、その場では終わりません。

最高記録と、その日の最高記録は、この端末に保存されます。0点は記録しません。

終了画面の X と LINE のボタンから、いまの得点をそれぞれの投稿画面で共有できます。

## 開き方

ビルドは不要です。フォルダをウェブサーバーで公開するか、手元では次のように開きます。

```bash
python3 -m http.server
```

ブラウザで `http://localhost:8000/` を開いてください。`file://` では動きません。
